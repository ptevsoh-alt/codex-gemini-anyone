# Example General Skill

## Identity

- Skill ID: example.general
- Version: 1.0.0
- Mode: HANDOFF_ONLY

## Trigger

Use this skill when a request includes example, summarize, or handoff.

## Input

A task request string. The runtime passes the task envelope and does not inject credentials or browser state.

## Output

Return a structured summary and handoff notes. A provider handoff remains human-mediated.

## Dependencies

None.

## Example prompt

Summarize this request and prepare it for a human Gemini handoff.
